### 🚀 **مرحله ۱: نصب Docker**

Docker就像一个 ماشین مجازی است که همه چیز را برای شما ایزوله و آماده می‌کند.

1.  به وبسایت رسمی Docker بروید: [https://www.docker.com/get-started](https://www.docker.com/get-started)
2.  نسخه مناسب برای سیستم عامل خود (Windows, Mac, Linux) را دانلود و نصب کنید.
3.  بعد از نصب، Docker را باز کنید و صبر کنید تا حالت "Ready" را نشان دهد.

**نکته برای ویندوز:** هنگام نصب، اگر از شما پرسید "Use WSL 2 instead of Hyper-V" گزینه Yes را انتخاب کنید.

### 🛠️ **مرحله ۲: راه‌اندازی وردپرس با Docker (بسیار آسان)**

ما از یک فایل تنظیمات آماده استفاده می‌کنیم.

**قدم ۱: ایجاد یک پوشه برای پروژه**
- یک پوشه جدید در دسکتاپ یا هر جای دیگر با نام `my-farsi-shop` ایجاد کنید.

**قدم ۲: ایجاد فایل `docker-compose.yml`**
- داخل این پوشه، یک فایل جدید با نام دقیق `docker-compose.yml` ایجاد کنید.
- محتوای زیر را در آن کپی و ذخیره کنید:

```yaml
version: '3.8'

services:
  db:
    image: mysql:5.7
    volumes:
      - db_data:/var/lib/mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: password
      MYSQL_DATABASE: wordpress
      MYSQL_USER: wordpress
      MYSQL_PASSWORD: wordpress

  wordpress:
    depends_on:
      - db
    image: wordpress:latest
    ports:
      - "8000:80"
    restart: always
    environment:
      WORDPRESS_DB_HOST: db
      WORDPRESS_DB_USER: wordpress
      WORDPRESS_DB_PASSWORD: wordpress
      WORDPRESS_DB_NAME: wordpress
    volumes:
      - ./wp_data:/var/www/html

volumes:
  db_data:
  wp_data:
```

**قدم ۳: اجرای پروژه**
- Docker را باز کنید.
- در خط فرمان (Terminal یا Command Prompt) به پوشه `my-farsi-shop` بروید. یا اینکه معمولاً در نرم‌افزار Docker می‌توانید مسیر این پوشه را مشخص کنید.
- دستور زیر را اجرا کنید:

```bash
docker-compose up -d
```

- صبر کنید تا دانلود و اجرا شود (ممکن است چند دقیقه طول بکشد).

**تبریک! وردپرس شما الآن در حال اجراست.**
- مرورگر خود را باز کنید و به آدرس زیر بروید:
    ```
    http://localhost:8000
    ```
- الآن باید صفحه نصب وردپرس را به زبان انگلیسی ببینید.

### 🏪 **مرحله ۳: نصب وردپرس و پلاگین فروشگاه (WooCommerce)**

**قدم ۱: تکمیل نصب وردپرس**
- در صفحه `http://localhost:8000`، زبان **فارسی** را انتخاب کنید و Next بزنید.
- اطلاعات زیر را پر کنید (بقیه تنظیمات پیش‌فرض خوب است):
    - **Site Title:** نام فروشگاه شما (مثلاً: فروشگاه اینترنتی من)
    - **Username:** یک نام کاربری برای خودتان (این را به خاطر بسپارید!)
    - **Password:** یک رمز عبور قوی (این را حتماً یادداشت کنید!)
    - **Your Email:** ایمیل خودتان
- روی "Install WordPress" کلیک کنید و سپس "Log In".

**قدم ۲: نصب پلاگین WooCommerce**
- حالا به پیشخوان وردپرس وارد شده‌اید (`http://localhost:8000/wp-admin`).
- از منوی سمت راست، به مسیر **پلاگین ها > افزودن** بروید.
- در کادر جستجو، `WooCommerce` را تایپ کنید.
- روی دکمه **"نصب"** و سپس **"فعال‌سازی"** کلیک کنید.

**قدم ۳: راه‌اندازی Wizard فروشگاه**
- بعد از فعال‌سازی، یک راهنمای راه‌اندازی (Wizard) برای WooCommerce باز می‌شود.
- آن را دنبال کنید:
    - **آدرس فروشگاه:** کشور، شهر و آدرس خود را وارد کنید.
    - **نوع فروشگاه:** محصولات فیزیکی را انتخاب کنید.
    - **اطلاعات فروش:** در ابتدا می‌توانید بگویید "فروش ندارم" تا بعداً تنظیم کنید.
    - **پرداخت:** در ابتدا می‌توانید فقط "مستقیم" (Direct Bank Transfer) را فعال کنید. بعداً درگاه پرداخت ایرانی مثل زرین‌پال را اضافه می‌کنیم.
- این مراحل را تکمیل کنید تا اسکلت اصلی فروشگاه شما ساخته شود.

### 🎨 **مرحله ۴: نصب و شخصی‌سازی یک قالب فارسی**

**قدم ۱: نصب یک قالب مناسب**
- از منوی سمت راست، به **ظاهر > قالب ها** بروید.
- روی **"افزودن"** و سپس **"قالب برگزیده"** کلیک کنید.
- یک قالب ساده و سازگار با WooCommerce و RTL (مثل "Storefront" یا "Astra") را نصب و فعال کنید.

**قدم ۲: فارسی‌سازی و تنظیمات اولیه**
1.  **زبان:** مطمئن شوید زبان وردپرس در **تنظیمات > عمومی** روی فارسی ست شده.
2.  **مقادیر عددی:** برای نمایش صحیح اعداد در فروشگاه، پلاگین **"Persian WooCommerce"** یا **"WP-Parsidate"** را نصب و فعال کنید. این پلاگین تاریخ، قیمت و ارز را به صورت فارسی درست می‌کند.
3.  **منوها:** به **ظاهر > منوها** بروید و یک منوی اصلی برای سایت خود بسازید (مثلاً شامل: خانه، محصولات، تماس با ما).

---

### ✅ **کارهای بعدی برای تکمیل فروشگاه**

- **اضافه کردن محصول:** از منو به **محصولات > افزودن** بروید.
- **درگاه پرداخت:** پلاگین درگاه پرداخت ایرانی (مثلاً برای زرین‌پال یا پارسیان) را نصب و تنظیم کنید.
- **صفحات ضروری:** صفحات "تماس با ما" و "درباره ما" را ایجاد کنید.

### 🛑 **توقف و اجرای مجدد پروژه**

- وقتی کارتان تمام شد، در ترمینال داخل پوشه پروژه، دستور زیر را بزنید تا همه چیز خاموش شود:
    ```bash
    docker-compose down
    ```
- برای اجرای مجدد، فقط کافیست دوباره دستور زیر را بزنید:
    ```bash
    docker-compose up -d
  
  ----------
  docker-compose up -d --force-recreate
  ---------------
    ```
- **همه داده‌های شما (محصولات، تنظیمات) در پوشه `wp_data` ذخیره می‌شوند و از بین نمی‌روند.**
